# Mark My Words: assistant entry

For editorial work, use [the compact routing index](docs/routing.md) to infer the task from ordinary language. No code word is required; "Use Mark My Words" is an optional explicit request. Ordinary conversation needs no editorial workflow.

Read [the editorial contract](docs/editorial-contract.md) before acting, once per verified framework revision in the current context; reread it when the revision changes or the rules are no longer available. Then load only the selected skill and necessary source material. Do not read the full skill catalog, every role's skills, or every state file.

Five working roles organize the experience: Editor, Researcher, Reader & Brand Reviewer, Challenger, and Producer. The nine existing Copilot names remain compatibility entry points, not nine mandatory calls.

Resolve private context through the authorized CONFIG_REPO/WORKING.md only when accessible and relevant. Public configurations are generic templates. Repository instructions are not automatically installed in the host. Retrieval is prompt-guided; loading less now does not remove previously read context.

Keep private configuration, drafts, reviews and source conversations out of this public repository and its issues/PRs. Follow host permissions and safety rules. Editorial readiness never authorizes publishing, merging, deploying or external sending.
