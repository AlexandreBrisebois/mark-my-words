# On-demand skill catalog

Selection metadata, not a reading list. The compact [routing index](routing.md) is the entry point. Read only the selected section/row or directly open its SKILL.md. Paths below are relative to the repository root: `.github/skills/<name>/SKILL.md`.

## Shared contract for every skill

Use only within the user's requested outcome. Minimum inputs include current intent and any relevant protected author choices. Draft-related work needs the actual canonical artifact and revision; review output records reviewed_revision, scope, outcome and concrete findings. State/configuration is private and only loaded when authorized, accessible and necessary. Missing inputs are disclosed, not invented. Preserve current user intent over editorial defaults.

Each row adds skill-specific use, inputs, output and stop condition. Stop also on budget or a decision/access/evidence blocker. A stop condition is not permission to publish. Related skills are candidates, not mandatory dependencies; no skill requires loading every skill in its working role. The [editorial contract](editorial-contract.md) governs conflicts with older examples.

## Runtime limits

This catalog does not install skills, create tools, select model APIs or automatically fetch private repositories. Connector reads remain prompt-guided. Avoiding unnecessary fetches does not unload context already read. Do not claim token, latency or quality savings without measurement.
