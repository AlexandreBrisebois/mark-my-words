# Mark My Words

An editorial framework for an author and an assistant: sharpen the idea, protect the author's voice, and prepare work for a human to publish.

## Start

Give your assistant [AGENTS.md](AGENTS.md), your request, and the current draft if there is one. Ask naturally: "Tighten this paragraph," "Check this claim," or "Give this an accusation audit."

One Editor owns the draft. Four on-demand roles help only when needed: Researcher, Reader & Brand Reviewer, Challenger, and Producer. This is a set of instructions, not an installed plugin, executable workflow, or automatic publisher.

Personal context and real work stay in your private workspace. Point the assistant privately to your `WORKING.md`; [configuration](docs/configuration.md) describes what it should map. No personal configuration belongs in this repository.

The assistant returns the requested result, evidence gaps, and the smallest next step. You choose wording and acceptable editorial risk. Preparing a publication package never authorizes publishing it.
