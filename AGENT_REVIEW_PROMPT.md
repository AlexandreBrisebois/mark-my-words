# Agent Review & Refactor Prompt

Use this prompt to guide future refactors of your GitHub Copilot agents into the modular, skill-based architecture.

---

**Prompt Start:**

I want to refactor @[AGENT_FILE] into a modular, skill-based architecture. 

**DO NOT** modify the yaml frontmatter yet.
**DO NOT** overcompress and lose the efficacy and nature of the agent

**YOUR MISSION:**
1. **Evaluate** what the agent does by reading @[AGENT_FILE] and its associated specification @[SPEC_FILE].
2. **Interview** me relentlessly about every aspect of this agent's design. Walk down each branch of the design tree, resolving dependencies between decisions one by one.
3. **Explore** the codebase instead of asking questions that can be answered by looking at existing configurations or state files.
4. **Recommend** an answer for every question based on the "Mark My Words" editorial standards and the "Config-Driven" architecture (Global Skills, Local Identities).
5. **Iterate** 1 by 1. Use my answers to identify the next most impactful design decision.

**THE DESIGN TREE BRANCHES TO COVER:**
- **Authority**: Where does the agent resolve its persona? (Global vs. Local)
- **Hierarchy**: What are the mandatory upstream dependencies? (Handoffs)
- **Output**: What is the primary artifact vs. chat dashboard content?
- **Conflict**: How does it handle irreconcilable feedback from other agents?
- **Integrity**: How does it prevent fabrication or "generic" AI behavior?
- **Skills**: What logic should be extracted into `.github/skills/<name>/SKILL.md` to optimize tokens?

**THE ARCHITECTURAL STANDARDS (NON-NEGOTIABLE):**
1. **Global Skills First**: Always leverage `mmw-editorial-standards`, `mmw-audience-modeling`, and `mmw-codename-gen`. Do not re-define voice, personas, or slug logic in local agent instructions.
2. **Stateless Snapshot**: All specialist `.state.md` files must be overwritten with the "Latest Truth" (Clean Spec) only. No historical logs.
3. **Model Targeting**: Use `model: ['gpt-4.1']` in the YAML frontmatter.
4. **Handoffs**: Use the `handoffs` frontmatter field to define the next logical step in the editorial relay.
5. **Codename Integrity**: Use the slug generated by `mmw-codename-gen` for all generated draft/state filenames.

**MUST** go through each question one by one. Once we reach a shared understanding, propose a modular skill structure optimized for GPT-4.1.
